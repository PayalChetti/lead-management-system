# Laravel Lead Management System

A web-based Lead Management System developed using Laravel.

## Features

- User Authentication
- User Management
- Role Management
- Lead Management
- Lead Status Master
- Lead Source Master
- Follow-up Management
- Dashboard
- Lead Reports
- Status Reports
- Source Reports
- Follow-up Reports
- Revenue Reports
- Search and Pagination
- Excel Export
- PDF Export
- Print Reports
- Responsive Bootstrap UI

## Technologies

- PHP
- Laravel
- MySQL
- Blade
- Bootstrap
- JavaScript
- jQuery
- HTML
- CSS

## Modules

### Dashboard

Provides an overview of:

- Total Leads
- New Leads
- Contacted Leads
- Qualified Leads
- Won Leads
- Lost Leads
- Today's Follow-ups

### Lead Management

Users can:

- Create leads
- Edit leads
- View lead details
- Assign leads
- Track lead status
- Track lead source
- Manage expected revenue

### Follow-ups

Users can manage:

- Follow-up date
- Follow-up type
- Follow-up status
- Follow-up notes
- Assigned users

### Reports

Includes:

- Lead Summary Report
- Status Report
- Source Report
- Follow-up Report
- Revenue Report

Reports support:

- Search/filtering
- PDF export
- Excel export
- Printing
